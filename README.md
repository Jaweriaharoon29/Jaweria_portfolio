# Jaweria Haroon — Software Engineer Portfolio

This version follows the generated visual mockup: dark plum/black background, coral-red accents, large hero typography, real profile photo, compact tech-stack cards, terminal learning panel, featured projects, certifications, GitHub repositories, statistics and contact area.

## Files
- `index.html` — structure and content
- `style.css` — visual design + responsive layout + animations
- `script.js` — interactions and live GitHub repository loading
- `data.js` — easiest place to keep adding projects/certifications
- `assets/profile.jpg` — supplied profile image
- `assets/Jaweria_Haroon_CV.docx` — CV download

## Add a project
Edit `data.js` and add an object to `featuredProjects` with `title`, `description`, `tech`, and `url`.

## Add a certification
Edit `certifications` in `data.js`.

## GitHub
The Live from GitHub section loads public repositories from `Jaweriaharoon29` using GitHub's public API. No private token is included.

## Run
Open `index.html`, or use VS Code Live Server for the best local experience.
